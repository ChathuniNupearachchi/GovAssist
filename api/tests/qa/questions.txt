# GovAssist conversational QA scenarios — read by tests/qa/harness.py.
#
# Rewritten in natural language: every line is phrased the way a Sri
# Lankan citizen would actually type it to a chat assistant — real
# people write incomplete sentences, misspell, give context before the
# question, and are often uncertain about what they need. Nobody types
# "68 old" or "urgent service."
#
# Format unchanged: one scenario per non-comment, non-blank line inside
# a "## CATEGORY: <letter> — <name>" block; consecutive non-blank lines
# with no blank line between them are turns of ONE multi-turn scenario
# on a fresh device_ref; a blank line starts a new scenario.
#
# Organized per service (design.md's rebuilt 7-service list), each
# covering: straightforward phrasings, an uncertain citizen, a citizen
# who over-explains before asking, misspelled/lowercase input, a
# mid-intake interruption, and a correction — plus general information,
# greetings, and the three kinds of out-of-scope refusal.
